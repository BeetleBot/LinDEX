Installation Instructions
------------------------------------------------------------------------
Installing system-wide adds the `lindex` command to your PATH, installs
the application launcher icon, and sets up desktop menu shortcuts.

1. Open your terminal in the extracted directory.
2. Run the installer with superuser privileges:

       sudo ./install.sh

3. Launch LinDex anytime from your application menu or by typing:

       lindex

To uninstall in the future, run:

       sudo ./uninstall.sh

------------------------------------------------------------------------
Troubleshooting & Support
------------------------------------------------------------------------
- Turn on USB Debugging on your phone: Settings > Developer options.
- Plug your phone into PC with USB cable once and allow debugging.
- Press [Alt] to release mouse/keyboard back to Linux host anytime.
- Report issues or check documentation at: https://github.com/BeetleBot/LinDEX
